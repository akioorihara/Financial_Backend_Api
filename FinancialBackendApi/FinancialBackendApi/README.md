# Financial_Backend_Api
This is a backend API for a financial application that provides various endpoints for managing financial data, transactions, and user accounts. The API is built using modern web technologies and follows RESTful principles to ensure scalability and ease of use.

## Technologies Used
C# Technologies Used
- ASP.NET Core: A cross-platform framework for building web applications and APIs.
- Entity Framework Core: An object-relational mapper (ORM) for database access.
- SQL Server: A relational database management system for storing financial data.
- Swagger: A tool for documenting and testing APIs.
- JWT (JSON Web Tokens): For secure authentication and authorization of users.
- AutoMapper: A library for mapping between different object models.
